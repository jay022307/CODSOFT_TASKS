# Sales Prediction using Python

## Project Overview
This project predicts product sales based on advertising expenditure on TV, Radio, and Newspaper using a Linear Regression model. The goal is to analyze the relationship between advertising budgets and sales and build a predictive machine learning model.

## Dataset
- File Name: advertising.csv
- Total Records: 200
- Features:
  - TV
  - Radio
  - Newspaper
- Target Variable:
  - Sales

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Workflow
1. Import required libraries
2. Load the dataset
3. Explore the dataset
4. Check for missing values
5. Visualize the data
6. Select features and target variable
7. Split the dataset into training and testing sets
8. Train the Linear Regression model
9. Predict sales
10. Evaluate the model using MAE, MSE, RMSE, and R² Score

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## Results
The Linear Regression model successfully predicts sales based on advertising budgets. The model was evaluated using standard regression metrics and demonstrated good predictive performance.
