# 🌸 Iris Flower Classification

## 📌 Project Overview

The objective is to build a Machine Learning model that classifies Iris flowers into three different species based on their sepal and petal measurements.

## 🎯 Objective

Develop a classification model that predicts the species of an Iris flower using the following features:

- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

The model predicts one of the following species:

- Iris-setosa
- Iris-versicolor
- Iris-virginica

---

## 📂 Dataset

- **Dataset Name:** Iris Dataset
- **Total Records:** 150
- **Features:** 4
- **Target Variable:** Species

## 📊 Project Workflow

1. Import required libraries
2. Load the Iris dataset
3. Explore and analyze the dataset
4. Check for missing values
5. Visualize the data using Pair Plot and Heatmap
6. Split the dataset into training and testing sets
7. Train a Decision Tree Classifier
8. Make predictions
9. Evaluate the model using:
   - Accuracy
   - Classification Report
   - Confusion Matrix
10. Predict the species of a new flower

---

## 🤖 Machine Learning Algorithm

**Decision Tree Classifier**

Decision Tree is a supervised machine learning algorithm used for classification tasks. It learns patterns from the training data and predicts the species of new flowers based on their measurements.
